# Student Timetable Webpage

This project is a simple HTML webpage created for a Semester 1 practical evaluation. The webpage displays a weekly class timetable using an HTML table and demonstrates the use of basic HTML elements such as headings, paragraphs, text formatting, tables, colors, merged cells, and hyperlinks.

The page includes a title, student information section, a timetable covering Monday to Thursday, a highlighted lunch break, office hours spanning multiple time slots, and a link to the official university portal.

## Features
- HTML5 document structure
- Semester 1 class timetable
- Table with `colspan` and `rowspan`
- Text formatting using `<strong>`, `<em>`, and `<mark>`
- Colored table cells for better readability
- External hyperlink opening in a new tab
- Responsive viewport settings

## Technologies Used
- HTML5

## How to Run
1. Save the code as `index.html`.
2. Open the file in any modern web browser.
3. View the timetable and navigate to the university portal using the provided link.
